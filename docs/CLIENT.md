# 使用说明

完整解压 Windows x64 客户端包，运行「游戏启动器.exe」。保留同目录的 runtime、resources、licenses，不要只复制 EXE。游戏本体需自行准备，缺少界面组件时安装 Microsoft Edge WebView2 Runtime。

## 单机

在「单机游玩」导入本人账号 ZIP，核对 UID、角色及观测数量，选择「备份并导入」。首次定位本机原版游戏目录，退出后等待保存完成。已核验的 TapTap 与 B服固定版本均保留支持；版本不匹配会明确停止，不能靠关闭校验解决。

已有同 UID 存档可选择「仅补充星云树与探索历史」，在游戏和本地服务停止后操作，先备份并核对预览散列。共享频道且无法同时核对原角色 ID、UID 的景点／挑战状态不会自动写为个人历史；预览会提示本次未恢复部分。未知不代表未完成，原 ZIP 保留，可确认的个人挑战用时单独恢复；不会自动清除既有进度。生活历史需要对应页面的有效采集证据，旧包缺少响应时不能把显示次数当作原服完整历史。

「收藏家园」可保存独立家园 ZIP 或合集，再按收藏列表的屋主 UID 搜索并拜访。收藏是只读快照，不覆盖自己的布局，不代表原屋主在线。

「活动与通行证档期」可选择当前活动、通行证和历史扭蛋池。场景布置改变后完整退出游戏再启动。玩法使用已实现的本地规则，不保证与官服算法一致；付费、邀请召回和部分特殊玩法未开放。

## 邀请联机

只需玩家客户端，不需要服务端管理或部署包。在「连接与启动」导入管理员私下发给本人的 Key，核对服务器与 UID，定位本机原版游戏后进入。每人使用自己的 Key，不公开或共享账号凭据；需要恢复旧账号时，将本人合格采集包私下交管理员审核。

本轮邀请公测使用 TapTap 程序 2026-10-21-14-05-50、资源 2026-11-25-19-54-41。B服单机可用；联机是否支持取决于服务器 Key 对应的程序和资源组合，当前测试服的旧 B服资源配置不适用于本机较新的 B服安装。不要混写两渠道版本或关闭校验。

已恢复账号双方都有明确好友证据时，可沿用原好友会话；未知联系人、单向申请或未恢复的联系人不会自动成为可私聊账号，删除和拉黑仍生效。

## 保存与更新

存档、连接设置和日志位于当前用户 AppData/Roaming/OverField Desktop/client，更新后保留。原版游戏的不可变资源仍需保持可访问。若启动前提示副本路径过长或真实清单缺失，应按提示缩短路径／核对安装，不生成假的版本文件。

「客户端设置 → 版本更新」可检查、下载并更新，运行中的游戏退出并完成保存后才能安装。更新先验签与核对内容；支持的增量包复用已校验文件，失败可回退完整包。完整包手动安装入口保留。

反馈请给版本、渠道、复现步骤及错误文本，不公开账号包、Key、数据库或抓包文件。第三方许可及单机组件对应源码随包保留。
