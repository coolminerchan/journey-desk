# 使用说明

完整解压 Windows x64 客户端包，运行「游戏启动器.exe」。请保留同目录的 `runtime`、`resources` 和 `licenses`，不要只复制 EXE。游戏本体需自行准备。

## 单机

打开「单机游玩」，导入自己的账号 ZIP，核对后选择「备份并导入」。首次启动时选择已有的游戏目录。退出后等待保存完成。

选中存档后可点击「收藏家园」，选择独立家园 ZIP 或合集保存。之后在游戏内打开好友搜索，输入收藏列表里的屋主 UID，打开资料后选择家园拜访，即可游览保存的家园；自己的家园、物品与进度保持原样。收藏家园按保存时的快照展示，不能编辑或代表原屋主在线。

## 联机

在「连接与启动」导入管理员提供的统一 Key，核对服务器与 UID 后使用。首次定位游戏目录，之后点击「进入游戏」。Key 已包含连接和玩家信息，不要交给其他玩家。

## 更新

「客户端设置 → 版本更新」可检查、下载并更新。默认启动时检查，可自行关闭；不会自动下载或强制安装。运行中的游戏退出并完成保存后，才能更新。

优先直连 GitHub，连接失败时尝试备用线路。更新通过签名、文件摘要和包内容核验后替换原目录，完成后重新打开；失败保留旧程序与恢复记录。存档和连接设置保存在用户目录，不随程序更新清除。

支持增量更新的版本会优先只下载有变化的程序文件，界面显示预计下载大小。未改动的文件从本机复用并核对摘要；本机文件不匹配或增量包不可用时，自动改用完整更新。大文件自身发生变化时，仍需下载该文件。旧版第一次需完整升级到支持增量更新的版本，后续更新即可复用本机文件。

缺少界面运行组件时，安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/consumer/)。反馈问题请提供程序版本、Windows 版本和复现步骤，不要附上账号包、Key 或抓包文件。

依赖许可和对应第三方源码见 `licenses` 及运行组件中的说明文件。
